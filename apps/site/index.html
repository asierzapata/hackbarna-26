The practical part

A few things before you start.

What you’ll need, how rooms work, and what to expect from an early version of Kan.

Will Kan work on my Mac?

The current download is for Macs with Apple Silicon (M1 or later). There isn’t an Intel Mac, Windows, Linux, or mobile download here. If you’re reading on your phone, open this page on your Mac to install Kan.

What do I need to connect my AI?

Kan supports Devin and OpenAI Codex, one connected provider at a time. Sign in with a supported subscription or use an API key. Your provider’s plan, limits, and usage charges apply; API usage is billed separately from a ChatGPT subscription.

You’ll need the Devin CLI installed for Devin, or Node.js with npm/npx for the Codex adapter. An account alone isn’t enough to run the integration.

What does my team need to use rooms?

Rooms need an internet connection and a configured room server. Video and transcription also need the server’s Vonage integration.

Shared rooms are an alpha feature. The richest AI canvas tools currently work on solo boards; not every solo feature or rich content type is available in rooms yet. Start with a solo canvas to explore the broader toolset.

What works offline? What leaves my Mac?

Solo canvases are stored locally and remain available offline. AI features require internet access and send prompts and relevant canvas context to your chosen provider.

Shared rooms use a server. Video and transcription use Vonage. Network-backed content, such as map tiles and remote images, also needs a connection. Local storage does not mean that AI processing happens on your Mac.

How are my API keys handled?

If you connect with an API key, Kan saves it in macOS Keychain so it can reconnect. The Codex adapter also caches its authentication in its own configuration. Signing out removes Kan’s saved key and the adapter’s API-key cache.

Subscription sign-in uses the provider’s login flow. Signing out of Kan disconnects the agent; it does not sign you out of the provider in your terminal.

What should I expect from the alpha?

An early version for exploring a different way to work with AI. Expect bugs and changes, and keep a separate copy of anything important. Check AI-generated content before relying on it.

Found a problem or have an idea? Share feedback on GitHub. Issues are public, so leave out private canvas content, credentials, and diagnostic reports containing personal information.

What’s under the hood?

Kan uses Tauri for the desktop app, tldraw for the canvas, and the Agent Client Protocol to connect to AI agents. Canvas changes go through a scoped set of tools rather than giving the agent control of your desktop.

Your first canvas, in three steps.

  1. Install Kan on your Mac.

    Open the DMG and drag Kan Alpha into Applications.

  2. Review the macOS security prompt.

    This alpha is not signed with an Apple Developer ID or notarized. After trying to open it, go to System Settings → Privacy & Security. Only if you trust this download, choose Open Anyway and confirm.

    Read Apple’s guidance on opening downloaded apps
  3. Connect your AI and start a solo canvas.

    Install the Devin CLI or Node.js with npm/npx for Codex, then sign in through Kan. Add your context and ask for a first draft.
